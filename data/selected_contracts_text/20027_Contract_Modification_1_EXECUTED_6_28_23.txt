## **API Development – Release/Remand data from Court to Jail Manager** 

Tyler Technologies will develop additional APIs to include in Tyler’s API Toolkit to support receiving court data into Jail Manager. These new integration points will help to reduce the amount of paper and manual data entry for hearings, bonds, sentences, and court orders. 

In conjunction with existing APIs in Tyler’s API Toolkit these new APIs will allow a third-party system to: 

1. Create/Cancel Hearings on inmate records. (API 1&2 Add/Import/Update Hearing Data) (REQ-6001) 

   - a. Create new hearings for parties in Jail Manager. 

   - b. Cancel hearings previously sent for parties in Jail Manager. 

   - c. Hearings are created/canceled directly on the inmate’s record without user intervention. 

   - d. Records that cannot be matched to an existing party are directed to a queue for a user to manually link. 

2. Add bond settings and bond conditions to booking records. (API 3 Import Bond Setting and Bond Condition data) (REQ-6002) 

   - a. Create new bond settings and associated bond conditions for charges on in-custody booking records. 

   - b. Bond settings and bond conditions are imported directly to the booking record without user intervention. 

   - c. Records that cannot be matched to an existing booking record are directed to a queue for a user to manually link. 

3. Create sentence import tasks in a task queue for review and processing. (API 4 Import Sentence/Remand data & documents to task queue) (REQ-6003) 

   - a. Create tasks containing sentence data in a queue for in-custody booking records. 

      - i. Attach the associated sentencing document to the task for review. 

   - b. From the task, an end-user can initiate the sentence data import. 

      - i. The document attached to the task is added to the booking’s documents tab with the import action. 

- c. The task history is stored on the booking record. 

- 4. Er Create document import tasks in a task queue for review and processing. (API 6 Import Release documents to task queue)(REQ-6004) 

   - a. Create tasks in a queue with court documents attached. 

   - b. From the task, an end-user can review the document and then import it to the associated booking record. 

   - c. The task history is stored on the booking record. 

Separate task queues can be specified for each import, or a single queue can handle multiple types of records. 

The export of data from Jail Manager to the Court CMS will utilize the Configurable Integration Publisher service that is part of the Enterprise Justice API Toolkit. 

Existing Integration Toolkit APIs will not be modified. This includes the existing API for importing charge dispositions. API development is based on existing fields and functionality for Tasks and Queues, Bonds, Hearings and Charges. No modifications will be made to Jail Manager to support the integrations. 0.0°e
